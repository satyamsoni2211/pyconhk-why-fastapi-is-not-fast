# Why Your FastAPI Is Not Fast — reveal.js deck (PyCon HK 2026)

Open `index.html` in Chrome/Edge/Firefox. Works fully offline (reveal.js, fonts and template art are bundled).

| Key | Does |
|---|---|
| → / Space | next fragment / slide (code highlight steps, bars, timeline all advance on click) |
| S | speaker view with notes + timer (talk narration and timings are in the notes) |
| O or Esc | slide overview |
| F | fullscreen |
| B or . | blackout / pause |
| ? | all shortcuts |

PDF export: open `index.html?print-pdf` in Chrome → Print → Save as PDF (background graphics on).

Animated slides: 5 (async framing), 8 (blocking vs non-blocking timeline — 2 clicks), 9 (live-demo chart).
